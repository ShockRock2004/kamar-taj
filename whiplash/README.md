# whiplash

> "Not quite my tempo."

You solved it. The tests went green. You closed the tab and felt good about yourself.

That feeling is the problem. Nobody in an interview tells you the answer was fine but slow. They just stop replying.

This skill reviews your solution the way a panel actually would. You hand it a link or a screenshot or just the pasted code. It reads the constraints before it judges your speed. It traces your code on a real example before it dares call anything a bug. Then it scores you out of five on correctness and optimality and edge cases and code quality and how well you could explain it out loud.

Every complaint arrives with the exact input that breaks you and the exact line that replaces it. Never "consider improving this". It shows you the improvement.

Then it ends with the best possible solution written in your language. Fully compilable. Commented on every line a beginner would trip over. That section is the one you actually scroll to so it never gets skipped.

It is hard on the code and never on you. It will not inflate a mediocre answer to be polite. Being polite now is how you get rejected in six weeks.

By default it judges against a new grad bar at a top tier product company and the correctness first bar that banks use. Tell it your own target companies or level and it will use yours instead.

## Install

It comes in the main kamar-taj bundle at https://github.com/ShockRock2004/kamar-taj
or you can just grab this single folder.

```bash
cp -R whiplash ~/.claude/skills/
```

Restart Claude Code and run /whiplash. Find the full protocol in SKILL.md.

Fair warning. It is not going to say good job.
